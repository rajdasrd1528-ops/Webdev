# P4 – README Documentation and Git Tags

# 1. Open your project folder
cd my-portfolio

# 2. Check Git status
git status

# 3. Open README.md in VS Code
code README.md

# 4. Add README documentation
# Write your project details, description, features and installation steps in README.md

# 5. Add README file to staging area
git add README.md

# 6. Commit README changes
git commit -m "Add project documentation"

# 7. Create a version tag
git tag -a v1.0 -m "First portfolio version"

# 8. View all Git tags
git tag

# 9. View tag details
git show v1.0

# 10. Push commits to GitHub
git push origin main

# 11. Push tags to GitHub
git push origin --tags

# 12. Check final Git status
git status
