 About This Project

This repository contains my Web Development Laboratory practical work, completed as part of my BTech CSE + AI curriculum.

The main objective of this project is to understand the fundamentals of web development and gain practical experience with HTML, CSS, Terminal, Git and GitHub.

I have organized the practicals into different sections, covering everything from basic terminal navigation to responsive website layouts.

 Learning Objectives

- Understand terminal commands and folder management.
- Learn Git and GitHub version control.
- Create structured web pages using semantic HTML.
- Apply CSS styling and design principles.
- Build responsive layouts using Flexbox and CSS Grid.
- Understand CSS positioning and reusable design tokens.

 Practical Modules

Module 1: Terminal, Git & GitHub

- P1: Project Folder and Terminal Navigation
- P2: Portfolio Repository with Initial Commit
- P3: Feature-Branch Git Workflow
- P4: GitHub README and Version Tags

Module 2: HTML & CSS Foundations

- P5: Semantic Bio Page
- P6: Full Portfolio Page Structure in Semantic HTML
- P7: Design Tokens and Typography System in CSS
- P8: Sticky Navbar and Card Overlay Using CSS Positioning
- P9: Responsive Navbar and Card Grid Using Flexbox

Module 3: CSS Layout Systems

- P10: Portfolio Header and Footer with Advanced Flexbox
- P11: Newspaper-Style Three-Column Layout with CSS Grid
- P12: Portfolio Projects Grid with Advanced CSS Grid
- P13: Choosing Between Flexbox and Grid for a Shared Layout

 How to Run

1. Clone this repository.
2. Open the project folder in Visual Studio Code.
3. Select the practical folder you want to explore.
4. Open its "index.html" file in a browser.
5. Check and modify the CSS file to experiment with the design.

Key Takeaways

Through these practical exercises, I am developing a better understanding of how websites are structured, styled and organized.

This project represents my learning journey from basic HTML elements to responsive layouts and professional development workflows.
